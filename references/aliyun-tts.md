# 可选路径：阿里云百炼配音

这是服务选择与调用前检查单，不是冻结某个 SDK、模型或 HTTP 参数的实现。接口、模型可用性、音色和计费会变化，实际调用前查[官方非实时语音合成文档](https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide)及其模型专属 API。

## 接入前

- 明确地域。用户选择北京时，核实北京地域的 API Key、模型和 endpoint；不能混用其他地域凭据，也不因失败静默跨区域。
- 查所选模型的音色、指令控制、SSML、输出格式、长度限制和速率限制，不能把另一模型示例直接套过来。
- Key 由用户在本地安全配置，优先使用宿主凭据管理或环境变量。百炼文档使用 `DASHSCOPE_API_KEY`；只检查存在性，不输出值，不写到请求日志或生成参数里。
- `HF_TOKEN` 是另一服务体系的凭据，不能拿来调用百炼。服务切换应更改适配器及配置，不只是替换密钥名称。
- 先展示将发送的开场试听文本和可能产生费用的范围，获准后只生成该范围。全文合成另按授权执行。

## 本地记录

只记录：提供商、地域、模型、音色、非敏感风格参数、请求文本哈希、发音词典版本、生成时间、音频格式及文件哈希。私密请求标识和带签名下载 URL 留在内部工作目录，不进入公开交付。

音频返回后先检查状态、非空内容和可解码性，再使用。及时保存成持久本地文件，不让成片工程依赖临时链接。非流式和流式响应处理要以实际 API 为准，不能将服务错误页面当作 WAV。

如果选择流式 PCM，依据接口声明的采样率、位深、通道和编码正确封装，不能猜参数。分段重试时防止重复拼接。

## 历史经验，不是当前推荐型号

一次早期制作尝试过官方演示服务，受额度限制后转向用户选择的百炼北京路径，并重新确认开场试听。历史使用的 Serena 女声和模型组合只说明当时的选择，不能保证当前账户、地域或模型继续提供同样声音。

按自然段生成、试听认可后才做全片、只修受影响片段，以及重新对齐时间轴，是可复用流程；特定音色 ID、endpoint 和价格不是可以永久复用的事实。

本仓库不包含付费调用脚本，也不会读取 Key 或发起合成。使用时通过官方客户端或已审核适配器完成，并遵守当前会话的授权范围。
