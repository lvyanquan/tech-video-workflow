# tech-video-workflow

**从源码与技术资料，到讲得清楚、看得明白的技术视频。**

一个面向技术科普、版本发布和功能解读的 Agent Skill。与 `tech-article-workflow` 分工：文章与视频可以共用核实后的事实，但视频需要重新设计分镜、旁白和时间轴，不直接把文章塞进幻灯片。

## 沉淀了什么

- 先完成设计文档，再制作 Remotion 动画。
- 从用户问题和收益出发，避免开发者视角的代码堆砌。
- 官方图标取材、来源记录及实际画面检查。
- 短片试听 → 选声确认 → 分段合成 → 读音校正 → 全片验收。
- 分离显示文字与发音输入，避免字幕出现版本号读音或项目谐音。
- 换声后按真实音频重新排期，不硬套旧字幕与章节。
- 区分完整稿、精简稿和声音修订；用户选定的基线优先。
- 本地导出、媒体检查、素材清单及明确的验证边界。

这不是“一条命令保证高质量成片”的生成器。它提供决策与制作流程，以及两个可测试的本地辅助工具；动画和主观质量仍需实际制作、预览与试听。

## 使用

仓库根目录即 Skill。将完整目录放到 Agent 支持的 Skill 目录，或让 Agent 显式读取 [SKILL.md](SKILL.md)。具体安装入口以宿主为准。

```text
使用 $tech-video-workflow，根据指定发布版本的源码和官方资料，
制作一支面向数据集成用户的讲解视频。先完成设计文档，
以具体用户收益解释功能，保留使用边界，不直接展示源码。
使用 Remotion 和必要的官方图标，先做一段配音试听，
最后交付本地 MP4、SRT、旁白稿和可重渲染工程。
```

```text
使用 $tech-video-workflow，以我认可的完整版为基线，只替换配音。
希望采用温柔、专业的女声，先试听包含版本号和项目名称的段落。
不要删章节、套用精简稿或整体加速；重建字幕与动画时间轴。
```

```text
使用 $tech-video-workflow，修正某个时间点的专名发音，
只重做相关自然段并核查接缝。显示名称不变；
如果时长改变，更新后续字幕、章节和导出文件，并报告差异。
```

## 依赖与验证

工具使用 Python 3.10+ 标准库，无 Python 第三方依赖：

```bash
python3 -m unittest discover -s tests -v
```

`inspect_media.py` 另需 FFmpeg 和 FFprobe；`build_timeline.py` 只支持本地非压缩 PCM WAV、整数帧率、顺序不重叠场景。其他媒体请先规范转换，或在制作工程中使用适合的时间轴实现。

Remotion、浏览器、中文字体和 TTS 服务不随仓库安装。锁定制作工程实际依赖版本，按需查官方文档。仓库的时间轴示例不是可播放成片，故意不附带真实客户音频。

自动测试只能验证工具行为，不能证明事实准确、画面美观、读音自然或主观音画同步。不要把机器校验写成人工听审结论。

## 安全与许可

- 只向 TTS 发送获准的旁白文本；不上传源文档、源码和内部信息。
- 试听、全片及跨平台重试分别遵守授权；不自动购买或绕过额度。
- 公开仓库不包含实际视频、内部链接、个人路径、密钥或第三方文章全文。

- Remotion 适用许可、服务地域、音色和计费条件需在使用时核实；本 Skill 不替你购买或授予第三方权利。
